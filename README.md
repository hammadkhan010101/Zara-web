# Zara Clone (Frontend)

A responsive frontend clone inspired by the official Zara website. This project was built to practice modern frontend development, responsive layouts, and clean user interface design.

## 🚀 Features

* Responsive homepage design
* Modern navigation bar
* Hero banner section
* Product listing cards
* Category sections
* Hover effects and animations
* Responsive layout for desktop, tablet, and mobile
* Clean and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

## 📂 Project Purpose

This project was developed for learning and improving frontend development skills. The main objective was to recreate a professional e-commerce user interface while following responsive web design principles.
